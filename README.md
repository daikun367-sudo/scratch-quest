# SCRATCH QUEST

BASICとADVANCE各12章、72ミッションを収録した日本語の教室教材です。

## 起動と保存先

`npm run dev` で開発、`npm run build` で公開用に構築します。
D1の論理バインディングは`DB`。`db/schema.ts`と`drizzle/`でスキーマを管理します。実行時のDDLはありません。
ローカル検証では`drizzle/`の未適用SQLを番号順にローカルD1に適用します。公開時はSitesがマイグレーションを適用します。
先生のパスワードは`TEACHER_PASSWORD_HASH`という秘密設定です。形式は32文字のsalt（hex）とPBKDF2-SHA256 100,000回の32-byteハッシュをコロンで連結したもの。平文パスワードはソースや配信ファイルに置きません。ローカルのみ、Git管理外の`.dev.vars`に同じ設定を入れます。

## アカウント

- 名前とパスワードで登録・ログイン。同一アカウントは複数端末で利用可能。
- パスワードはsalt付きハッシュ、セッションはランダムなトークンのハッシュをD1に保存。
- セッションCookieはHttpOnly / SameSite=Strict、本番HTTPSではSecure。7日で失効します。
- 生徒は自分の記録だけにアクセス。先生は全生徒の進捗・授業設定・特別賞を管理。
- 更新時はOriginを検査し、サーバー側で役割・章の解放・設定と特別賞の変更権限を確認。
- ログインには短時間の試行回数制限。同時編集時には版を検査して上書き競合を防止。
- 保存完了前のログアウトは保存を待ちます。接続エラーは画面で通知します。
- 公開版と旧ローカルHTMLの記録は別管理。旧版の記録は書きだして、ログイン後に読みこめます。

## 月ごとの解放

日本時間、登録した年度の4月を起点とします。9月には4〜9月の6章、10月に7章が開きます。次の年度になっても既存生徒の記録をリセットせず、解放した章を残します。新しい年度に登録した生徒はその年度の4月から始まります。先生は全章を解放できます。

## 教材の編集

- `app/curriculum.json`: 教材本文・ヒント・賞
- `app/game.ts`: 月の判定、進捗、ミッション達成後の物語
- `app/novel.tsx`: ノベルゲーム形式の導入、人物、選択肢
- `app/accounts.tsx`: 登録・ログイン・保存
- `app/teacher.tsx`: 先生用画面
- `public/`: BASIC／ADVANCEマップ、人物、研究室背景

## 検証

型検査・公開ビルドに加え、`scripts/check-calendar.mjs`で日本時間の月境界・年度またぎ・教師の解放設定を検証しました。
`scripts/check-accounts.mjs`は起動済みローカル環境へ接続します。`TEST_TEACHER_PASSWORD`を環境変数で指定します。登録、重複名、ログイン、別セッションの記録復元、他ユーザーのデータ分離、先生用権限、Origin検査、競合、未来の章、設定・特別賞の改ざん拒否、授賞、ログアウトを検証します。検証アカウントはローカルのみ作成します。
ブラウザ操作による画面QAおよびWebMCP実行契約の検証は未実施です。WebMCP対応の実行コンテキストはこの環境で提供されませんでした。

## 自由制作・作品提出・教材ファイル

- 生徒の「自由制作」ではタイトル・説明とsb3または共有済みScratch作品URLを提出・再提出できます。章の画面から章にひもづけた提出もできます。
- 先生モードの「作品を見る」で生徒・自由制作／章の作品を絞り込み、コメントと確認済みの状態を保存できます。sb3はダウンロードしてScratchの「コンピューターから読み込む」で確認します。アプリ内でのsb3再生はありません。
- 「章のファイル」でコース・章ごとに素材用と答え用を1点ずつ保存・差し替え。答えは初期非公開。個別公開しても授業設定の「答えを隠す」が優先されます。解放前の章のファイルは生徒に渡しません。
- ファイル本体は非公開R2（論理バインディング`FILES`）、提出内容・参照・コメントはD1に保存。認証したダウンロード経由でのみ取得可能。生徒は自分の作品と公開された教材のみ、先生は全提出作品にアクセスできます。
- sb3は1ファイル10MB以内、project.jsonは展開後2MB以内。ZIP構造とScratch 3の作品情報を検査します。
- `scripts/check-files.mjs`はローカル環境で提出・ダウンロード・9MBアップロード・不正ファイル・権限分離・コメント・競合・章ファイル差し替え・答え非公開・月ロック・容量制限を検証します。`TEST_TEACHER_PASSWORD`を指定してください。
